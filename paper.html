ReRoom: Reference-Guided 3D Scene Retargeting via Topology-Preserving Hierarchical Flow and Differentiable Geometric Projection

核心問題:在任意非均勻邊界形變下,如何同時保證場景拓撲不變性與物理硬幾何約束,且無需耗時的測試期優化?

摘要 Abstract

室內設計的身分在於空間關係與功能組合(Motif),而非絕對座標。本文定義參考導向的 3D 室內場景遷移:給定使用者偏好的參考設計 \(S_\text{ref}\) 與形狀 / 面積 / 長寬比任意變化的目標房間邊界 \(P_t\),自動完成佈局遷移。

任務有內在矛盾 — 既要保留參考的物件組成、空間關係、Motif 與風格,又要符合新房間的硬幾何(貼牆、不出界、不碰撞)。全域座標生成會破壞意圖;仿射形變會拉散 Motif;測試期多步優化耗時且陷入局部極小;硬吸附後處理則撕裂流形拓撲並誘發次生碰撞。我們提出:

  • 層級度量流(Topology-Preserving Hierarchical Flow) — 度量重參數化流形 \(\Phi_\mathcal{G}\),證明 Motif 在各向異性形變下的拓撲不變性(命題 1),並推導流形拉回(Pullback Jacobian)的可行性能量引導(命題 2)。
  • 可微近端投影層 \(\Pi_\theta\) — 把幾何規整化寫成帶提案錨定的近端算子,以 \(K\) 步展開實現單步推論與梯度反傳,消除測試期優化(命題 3')。
  • 結構化預算前端 — 極端縮小戶型下依面積預算與意圖圖做成對剪枝與小尺寸資產替換,解耦離散拓撲調整與連續幾何生成。

在 3D-FRONT 與跨戶型測試集上,單次前向 + 單步可微投影即在投影消融中取得全場最低碰撞(1.41%)與最佳關係保持(\(S_\text{rel}=0.696\)),延遲遠優於多步優化。

一、緒論(Introduction)

設計身分假設(Design Identity Hypothesis):設計的本質是相對結構(Motif 內部間距、朝向對齊、靠牆特徵),而非全域絕對座標。基本矛盾:適應全新邊界 \(P_t\)(貼牆、防撞、不越界)的同時,嚴格守恆 \(S_\text{ref}\) 的意圖與 Motif 結構。

四步破題(Storyline)

① 困境 — 意圖是拓撲的,但生成流在全域座標積分:房間非均勻縮放時,Motif 內部度量距離隨房間放大 → 餐桌椅被拉散。

② 死穴 — 兩種現有解法都傷佈局:測試期能量優化(LEGO-Net 式 Adam / MCMC)慢且陷局部極小;硬吸附貼牆卻破壞拓撲(\(S_\text{rel}\!\downarrow\))並誘發次生碰撞(\(R_\text{col}\!\uparrow\))。

③ 洞察 — 層級拓撲保持流(命題 1)+ 流形拉回引導(命題 2)+ 端到端可微近端投影 \(\Pi_\theta\)(命題 3')。

④ 結論 — 單網路 + 單步可微投影,達最低碰撞(1.41%)與最高拓撲保持(\(S_\text{rel}=0.70\)),無測試期優化。

關鍵技術創新

  • 度量不變重參數化 — Parent-Relative 度量座標使 Child 尺度與房間幾何解耦(命題 1)。
  • 流形拉回引導 — 跨座標系 Jacobian,使全域物理約束連帶更新層級子節點(命題 2)。
  • 端到端可微近端投影 — 展開式算子取代後處理,得單網路 + 單步投影管線(命題 3')。
  • 因果反向變形語料 — 四道物理守門,保證訓練對具備因果遷移關係。

二、相關工作(Related Work)

2.1 室內場景生成與佈局

規則 / 能量式生成(PlanIT、Make-it-Home);深度生成佈局(自回歸 ATISS、場景擴散 DiffuScene / SceneFormer);佈局編輯與條件生成(LayoutDiffusion、LEGO-Net)。這些從先驗取樣或原地編輯,無一能把特定參考的組成與意圖綁定到新邊界。

2.2 連續正規化流與 Flow Matching

Rectified Flow 與條件流匹配(CFM);幾何與約束流形上的流匹配 — 本文層級度量流形的基礎。

2.3 約束生成與可微優化

隱式可微優化層(OptNet)在物理約束的應用;神經生成器 + 凸 / 近端算子的混合架構 — 我們 \(\Pi_\theta\) 的譜系。

三、問題定義(Formulation)

  • 參考場景 \(S_\text{ref}=\{(c_i,s_i,x_i^\text{ref},\theta_i^\text{ref})\}_{i=1}^N\):類別、三維尺寸、中心、偏航。
  • 目標邊界 \(P_t\in\mathbb{R}^{32\times6}\):32 個邊界取樣點(座標、高度特徵、內向法向量 \((n_u,n_v)\))。
  • 意圖圖 \(\mathcal{G}=(\mathcal{V},\mathcal{E},\alpha)\):物件為節點,邊帶關係型與彈性 \(\alpha_{ij}\in[0,1]\),誘導層級 parent map \(\pi:\text{child}\mapsto\text{head}\)。
  • 靠牆傾向 \(a_i\in[0,1]\):物件在參考場景的貼牆親和度。

狀態 \(x_i=(u_i,v_i,\cos\theta_i,\sin\theta_i)\in\mathbb{R}^4\),正規化到房間 MRR frame。採用帶 informative prior 的 Rectified Flow:把高斯起點換成參考佈局仿射投影進 \(P_t\) 加輕擾動,讓模型整流而非盲猜:

$$x_0=\mathcal{T}(S_\text{ref},P_t)+\sigma\epsilon,\qquad \mathcal{L}_\text{FM}=\mathbb{E}_{\tau}\big\|v_\theta(x_\tau,\tau,\mathcal{G},P_t)-(x_1-x_0)\big\|^2 .$$

4.2 Stage 1 — 離散語意拓撲調整

面積預算 \(\text{Area}_\text{budget}=\operatorname{clip}(\text{density}+\text{slack})\cdot\operatorname{Area}(P_t)\)。物件短邊大於房間內切圓直徑則剔除;語意錨件(沙發、床)受保護,改觸發同風格小尺寸資產替換。超預算時對稱成對剪枝次要物件(如餐椅),再依重要性序縮減 — 保持語意合法。

4.3 Stage 2 — 拓撲保持層級流

映射 \(\Phi_\mathcal{G}:x\mapsto z\):head 用絕對座標,child 用 parent-local 度量座標(\(\lambda=\text{REL\_SCALE}=3\) m):

$$z_h=x_h,\qquad z_c=\tfrac{1}{\lambda}R(-\theta_{\pi(c)})\big(x_c-x_{\pi(c)}\big),\quad \Delta\theta_c=\theta_c-\theta_{\pi(c)}.$$

命題 1 — 度量形變下的拓撲不變性

各向異性縮放 \(A=\mathrm{diag}(s_x,s_y)\) 下,child 度量偏移被 parent 絕對座標吸收,相對編碼尺度無關:

$$z_c(A\!\cdot\!P_t)=z_c(P_t)\;\Rightarrow\;\lVert x_c-x_{\pi(c)}\rVert\ \text{保持(至多至 parent 位姿)}.$$

房間拉伸時 Motif 不散架。證據:0.6 m 偏移在 3 m 與 4.5 m 房都給 \(z=0.2\);1.35× motif 保持 25→42%;1.0× raw \(S_\text{rel}=0.98\)。

骨幹為異質 Transformer DiT:Type-ID 區分全域錨點與相對子節點;dense pairwise bias 注入相對位移 / 角度;WallCrossAttention 把 32 邊界點設為牆 token(child 遮罩外牆注意力,\(P_t\) 才不會把椅子從桌邊扯走);child 損失權重 \(\lambda_\text{child}=10\approx1/\sigma^2\) 補償局部 / 全域尺度梯度。

命題 2 — 絕對空間能量的 Jacobian 拉回

可行性能量 \(\Phi=w_b E_\text{bound}+w_c E_\text{col}+w_{cl} E_\text{clear}+w_{wp} E_\text{wall}\) 定義在絕對空間;流在重參數化流形,故引導須拉回:

$$z\leftarrow z+d\tau\,v_\theta-d\tau\,\mathrm{ramp}(\tau)\,\nabla_z\Phi\big(\Psi_\mathcal{G}(\hat z_1)\big),\qquad \nabla_z\Phi=J_{\Psi_\mathcal{G}}^{\top}\,\nabla_x\Phi.$$

Jacobian 對 child 含 parent-motion 項 — 即「動 parent 帶動 child」的鏈式法則。實作即 decode → nudge → encode。

命題 3' — 端到端可微近端投影 \(\Pi_\theta\)(核心)core

幾何規整(貼牆 flush、朝向、Manhattan、非碰撞)寫成錨定於提案 \(x_0\) 的近端目標,投影為 \(K\) 步展開梯度算子:

$$\Pi_\theta(x_0)=\underset{K\text{ 步展開}}{\arg\min}\;\underbrace{w_a\lVert x-x_0\rVert^2}_{\text{錨定提案}}+w_f E_\text{flush}+w_o E_\text{ortho}+w_c E_\text{col}.$$

每步可微,故 flow-matching loss 能穿透投影反傳 — DiT 學會輸出已近 \(\Pi_\theta\) 不動點的佈局(OptNet / implicit-diff 精神,以顯式展開實現、無外部依賴)。得一個自洽的神經生成器 + 凸式投影系統。

性質(拓撲保持):錨定項把投影位移限在微觀尺度(均 19 cm),故 \(\Pi_\theta\) 只修小角度 / 貼牆偏差,不改拓撲:\(\lvert S_\text{rel}(\Pi(x))-S_\text{rel}(x)\rvert\le 0.005\)。少了錨定,純能量下降會漂移、扯散 motif(\(S_\text{rel}\!\to\!0.566\))。

五、因果資料與物理守門(Data)

無配對 retargeting 資料,故反向製造:取真實 3D-FRONT 場景為 GT \(S_\text{tgt}\),對邊界做參數化形變,再把佈局(每個 Motif 視為剛體)逆映射合成參考 \(S_\text{ref}\)。剛性保證訓練對反映物理因果的設計轉移。

5.2 四道物理守門

  • 面積比重採樣 — 限制 \(\rho\in[0.5,2.0]\),超範圍重採。
  • 出界守門(OOB) — 出界比例超標則剔除該形變。
  • 剛體共享平移 — 把戳出牆的家具整體往內推(出牆 25.1% → 1.1%)。
  • 三類碰撞審計 — 區分真碰撞、可疊放對(餐桌椅、床與床頭櫃)與 Z 軸分離(檯燈 / 地毯),使合成碰撞不劣於真實基線。

另建真實跨場景配對(類別 Jaccard > 0.6、錨點偏航差 ≤ 30°,空間代價矩陣 + 匈牙利對齊)作為 OOD 泛化測試 — 證明模型非只擬合合成變形。

六、實驗(Experiments)

3D-FRONT 臥室 / 客廳,固定測試集(12 跨場景配對 + 4 多尺度)。指標:關係保持 \(S_\text{rel}\) / \(S_\text{motif}\);物理可行 \(R_\text{col}\)、\(R_\text{OOB}\)、貼牆率;以及推論延遲。

七、討論與限制(Discussion)

  • 垂直維度 — 目前流形建模 2D 平面 + 偏航,垂直層疊與複式空間為 future work。
  • 統一離散-連續流 — 把 Stage-1 剪枝以 Dirichlet / categorical 流匹配融入流(存在+位姿聯合過程)理論可行;我們的原型能學會剪枝但品質尚不及分階段基線 — 開放方向。

防禦式定位

離散剪枝怎麼交代?  —  不寫「用 while-loop 砍椅子」,而定義為兩階段架構:(1) 圖論式預算結構化剪枝(離散決策);(2) 連續約束幾何合成(流形流)。設計上解耦,貢獻在 Stage 2。
合成資料怎麼交代?  —  不寫「寫了變形腳本」,而是帶嚴格守門的因果反向變形 — 保持物理因果與 Motif 剛性的逆邊界映射,四道物理守門,並以真實跨場景配對做 OOD 測試,證明非過擬合合成。
