Component studies

Style-aware retrieval, and the shape term

Each object is asked for a rescaled version of itself and the bank must find it. Keeping the reference asset costs a mean log-size error of 0.249, which is the do-nothing baseline. The two degenerate weightings are the controls: each wins its own metric and loses the other.

Table 9

The shape term is a canonical occupancy descriptor computed from the asset mesh, so retrieval can ask whether a candidate is the same shape and not merely the same size and style. It cuts shape distance by 28 % for a small size concession, and appearance similarity goes up rather than down. Measuring this exposed a bug that had silently disabled half of the retrieval objective: the per-category embedding cache dropped the appearance term entirely if a single asset in that category lacked an embedding, so on any partially embedded catalogue “balanced” and “size only” were literally the same retrieval.

What the global appearance score is worth

A whole-image CLIP similarity is reported and never scored, because it cannot tell a room you can walk through from one you cannot. Legality separates the three methods by 0.191 and Srel by 0.143; the whole-render CLIP score separates them by 0.018, and correlates with legality at −0.02 across 120 retargetings.

VLM semantic relations

The formulation keeps a vision-language model in a supplementary role — deterministic geometry and category rules do the work. Measured against those rules over 50 rendered rooms, a CLIP-backed extractor proposes 208 semantic relations of which 86 are ones the rules also found: precision 0.41, recall 0.17. Uncalibrated it answered “symmetric” for every pair it was shown. The number is the evidence for the formulation's own caution, so the extractor stays off the default path.

SAGE-10k augmentation

Open-vocabulary augmentation is worth exactly what it can substitute: a category the bank has never seen cannot be swapped however good the optimiser is. Merging pseudo-assets harvested from 402 SAGE rooms raises the fraction of reference objects with any substitution candidate from 94.0 % to 100 %, entirely through categories 3D-FUTURE's canonical mapping does not reach — bench, bookcase, fireplace, mirror, piano, plant, rug, stool, tv, wall art. It does not move the layout metrics, and should not be expected to.
